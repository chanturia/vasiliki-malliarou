# ΒΑΣΙΛΙΚΗ ΜΑΛΛΙΑΡΟΥ — Website demo

Πρόταση σχεδιασμού ιστοσελίδας στην κατεύθυνση **Ιβουάρ & μπρονζέ**.

[Άνοιγμα demo](https://chanturia.github.io/vasiliki-malliarou/)

Πέντε σελίδες: Αρχική, Το γραφείο, Τομείς δικαίου, Διαμεσολάβηση και Επικοινωνία.

Η φόρμα ελέγχει τα πεδία και εμφανίζει τοπική προεπισκόπηση. Δεν αποστέλλει email και δεν αποθηκεύει στοιχεία. Οι εικόνες και το μονόγραμμα αποτελούν οπτική πρόταση, όχι φωτογραφική τεκμηρίωση του πραγματικού γραφείου. Πρόκειται για demo και όχι για την επίσημη ιστοσελίδα του γραφείου.

## Τοπική προεπισκόπηση

Από τον φάκελο του repository:

```sh
python -m http.server 8743 --bind 127.0.0.1 --directory site
```

Άνοιγμα στο `http://127.0.0.1:8743/`.

Το GitHub Pages δημοσιεύει μόνο τον φάκελο `site/`, χωρίς μετατροπή ή build. Οι γραμματοσειρές περιλαμβάνουν τις άδειές τους στο `site/assets/`.
